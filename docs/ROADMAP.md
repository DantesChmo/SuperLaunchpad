# Roadmap

Состояние на 2026-10-22: вышла **1.1.0** (удаление приложений в Корзину из режима редактирования).

Правило: **одна фича — один минорный релиз.** Фиксы и мелкие улучшения без новой функциональности идут патчами (`1.N.x`) между минорами.

Размер: **S** — до дня, **M** — пара дней, **L** — сначала `architect`, потом код.

## 1.2.0 — Контекстное меню

Правый клик по иконке и папке. Сейчас все действия спрятаны за jiggle-режимом, а правый клик — первое, что пробует пользователь мака.

- Приложение: **Открыть**, **Показать в Finder**, **Переместить в Корзину** (переиспользует диалог из 1.1.0; системным приложениям пункт недоступен).
- Папка: **Открыть**, **Переименовать**, **Распустить папку** (приложения встают на её место в сетке).
- Пункт **Редактировать раскладку** — вход в jiggle-режим.
- VoiceOver: те же действия как accessibility actions.

## 1.3.0 — Скрытые приложения

Убрать из сетки, не удаляя: helper'ы, агенты, дубли, приложения, которые запускаются только из Dock.

- **Скрыть** в контекстном меню (1.2.0) и в jiggle-режиме.
- Settings → **Скрытые приложения**: список с кнопкой «Вернуть».
- Решить и зафиксировать: находит ли их поиск (предложение — да, с пометкой).
- Миграция: колонка `isHidden` в `appEntry`; скрытое приложение не занимает место в сетке.

## 1.4.0 — Новые способы открыть

Tahoe убрал Launchpad из Dock, а pinch конфликтует с системным жестом. Нужны привычные триггеры.

- **Значок в Dock** (опция, по умолчанию выкл.): клик открывает и закрывает лаунчер, как старый Launchpad. `setActivationPolicy(.regular)` + `applicationShouldHandleReopen`.
- **Горячий угол** (выбор угла или «нет» в Settings), с небольшой задержкой против случайных срабатываний.
- *Спайк внутри релиза:* клавиша Launchpad (F4) на клавиатурах Apple. Если перехват требует прав Input Monitoring или Accessibility — в этот релиз не берём, записываем вывод.

## 1.5.0 — Сброс и бэкап раскладки

Раскладку собирают часами, а вернуть «как было» сейчас можно только удалив `apps.db` руками.

- Settings → **Сбросить раскладку**: заново импортировать из системного Launchpad (если его база есть) / разложить по категориям / по алфавиту. С подтверждением.
- **Экспорт / импорт** раскладки в JSON: порядок, страницы, папки и их названия, скрытые приложения. Перенос на другой мак, бэкап перед сбросом.
- Перед сбросом автоматически сохранять бэкап.

## 1.6.0 — Умный поиск

Поиск — основной способ запуска у опытных пользователей. Сейчас он ищет только по подстроке в имени.

- Нечёткое совпадение и по первым буквам слов: `vsc` → Visual Studio Code, `sysset` → System Settings.
- Английское имя при русской локали системы и наоборот («Настройки» ↔ System Settings).
- Ранжирование: точное начало имени, потом частота запусков (счётчик запусков в БД).
- *Опция:* при пустом поиске первыми показывать часто запускаемые.

## 1.7.0 — Размер сетки и иконок

Самая частая настройка у альтернатив Launchpad: 7×5 мелко на 13" и пусто на 32".

- Settings: колонки × ряды (например от 5×4 до 9×7) и масштаб иконок, с живым предпросмотром.
- При смене размера страницы переразбиваются: порядок и папки сохраняются, приложения перетекают между страницами.
- **До начала:** разрезать `LaunchpadViewModel` (890 строк) на модели поиска, редактирования/drag и удаления. Иначе эта фича ляжет в тот же файл, что и всё остальное. Отдельный патч-рефакторинг, без изменения поведения.
- `Grid` перестаёт быть статикой: затрагивает `GridLayout`, `GridGeometry`, `LayoutMetrics`, `pageIndex` в БД. Нужен проект от `architect`.

## 1.8.0 — Внешний вид

- Фон: сила размытия, затемнение, вариант «размытые обои рабочего стола».
- Размер и видимость подписей под иконками.
- *Спайк внутри релиза:* иконки в стиле Tahoe (тёмные / прозрачные / тонированные по системной настройке). Если `NSWorkspace` не отдаёт нужный вариант — записываем вывод, в релиз не берём.

## 1.9.0 — Русская локализация

- String Catalog (`Localizable.xcstrings`) вместо разрозненных строк; `String(localized:)` уже местами есть, каталога нет.
- Русский + английский; README по-русски — отдельной страницей.
- Каталог упрощает переводы от контрибьюторов на другие языки.

## 1.10.0 — Клавиатурная навигация по сетке

Сейчас стрелки только листают страницы; иконки выбираются стрелками лишь в результатах поиска.

- Стрелки двигают фокус по иконкам, на краю — на соседнюю страницу; `Return` открывает приложение или папку; внутри папки — то же самое.
- Заметное кольцо фокуса, с учётом Increase Contrast.
- Учитывает размер сетки из 1.7.0.

## Патчи между минорами

Без новой функциональности, выпускать по мере готовности:

- **Чёткие иконки на Retina.** Иконки ужимаются до 128×128 px (литерал в `AppEnumerator`), а на экране они ~90–110 pt, то есть нужно ~200 px. Хранить 256 px, пересобрать кеш миграцией. Самый заметный визуальный дефект — **первым патчем**.
- **`~/Applications`** в сканировании и в `AppDirectoryWatcher`: туда Safari и Chrome кладут веб-приложения.
- **`AGENTS.md`**: «Known limitations» утверждает, что поиска, DnD и создания папок нет; в project map не хватает половины файлов. `/sync-agents-md`.
- Разрезать `LaunchpadViewModel` — перед 1.7.0 (см. выше).
- Swift 6 language mode / strict concurrency (сейчас `SWIFT_VERSION = 5.0`).

## Готовность минора

1. Фича смержена, тесты на неё зелёные на CI (UI-тесты — только на CI).
2. Полная регрессия один раз перед тегом, не после каждого шага.
3. Запись в `CHANGELOG.md`, тег `v1.N.0`, Sparkle и Homebrew обновляются из workflow.

## Сознательно не делаем

- **Developer ID и нотаризация** — аккаунта разработчика нет; остаёмся на ad-hoc и «Open Anyway».
- **Mac App Store** — песочница ломает глобальные мониторы жестов и перемещение в Корзину через Finder.
- **Синхронизация через iCloud** — сначала экспорт/импорт (1.5.0), дальше по спросу.
